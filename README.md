# 刷课酱 - 网课视频助手 & AI 解题助手（油猴脚本）

本项目是将 Edge 官方商店扩展 **大学搜题酱插件**（Extension ID: `abkclgdmdkokpdkbpdkoiiemhcaafbkg`）下载并逆向反编译，彻底剔除所有冗余追踪、推广、扫码登录以及 VIP 限制后，重新重构并移植而成的**油猴（Tampermonkey / ScriptCat）脚本**。

---

## 🌟 核心功能特性

### 1. 视频助手 & 自动连播
- **底层反检测倍速 HOOK**：在 `document-start` 阶段 Hook `HTMLMediaElement`，拦截播放器自身绑定的 `ratechange`、`seeked`、`seeking` 等监听器，防止被平台脚本强制重置为 1 倍速或阻断拖动。
- **自动播放与静音**：自动对音视频设置静音（绕过现代浏览器的 AutoPlay 限制）并自动调用 `play()`。
- **防暂停与自动解除遮罩**：自动识别超星视频批注弹窗、播放暂停遮罩，自动点击继续学习。
- **视频随堂弹题自动处理**：
  - 智慧树视频随堂测试：直接从 Vue 实例读取原生答案并自动提交关闭。
  - 超星视频弹出测验：自动提取题干，调用 AI 给出答案并自动勾选提交。
- **多平台自动跳转下一节**：
  - **超星学习通**：按【任务点队列】依次推进——识别当前页面所有 `/ananas/modules/*` 任务点（视频/音频/文档/测验/图文），**自动跳过已完成任务点**，视频结束后继续处理后续章节测验，全部处理完才点击【下一节】；
    全部学完（【下一节】隐藏/不存在）时记录“🎉 课程已全部学习完成”并停止，**不会读取课程目录回头补跳**；同时自动确认平台弹出的“当前章节还有任务点未完成”提示。
  - **智慧树**：小节列表中优先跳转到**之后第一个未完成**的小节（连播开关开启时）。
  - **智慧职教 ICVE**、**中国大学 MOOC**、**学堂在线** 等平台的视频接续播放。
  - **跨域子框架**：子框架只负责本框架内的媒体接管，播放完成后通过 `postMessage` 通知顶层统一跳转，避免多实例重复触发。

### 2. AI 解题助手（OpenAI 兼容接口）
彻底废弃原插件连接其官方私有付费接口的逻辑，全面升级为 **OpenAI 兼容格式** 请求：
- **自由配置 API**：用户可在前端界面中任意配置 `API Key`、`Base URL` 与 `Model`。
  - 支持官方 **OpenAI**（`gpt-4o-mini`, `gpt-4o` 等）。
  - 支持高性价比国内模型如 **DeepSeek**（`https://api.deepseek.com/v1`, 模型 `deepseek-chat`）。
  - 支持 **硅基流动 (SiliconFlow)**、**Moonshot (Kimi)**、**智谱 (Zhipu)**、**OneAPI / NewAPI** 中转。
  - 支持 **本地 Ollama / vLLM**（例如 `http://localhost:11434/v1`）。
- **智能题型解析与格式化 Prompt**：
  - 准确识别 **单选题**、**多选题**、**判断题**、**填空题**、**简答题**。
  - 超星章节测验、独立作业/考试按 **每批最多 4 题** 请求（例如 9 题拆为 4 + 4 + 1）；视频弹题使用同一 JSON 协议单题请求。
  - 超星启用 `response_format: {"type":"json_object"}`，返回 `{"answers":[{"id":"q1","answer":["B"]},{"id":"q2","answer":["A","C"]}]}`；通过题目 ID 对应答案，不依赖返回顺序。填空答案使用数组，判断题保留实际选项顺序。
  - JSON 格式错误、未知/重复 ID、缺失或非法答案均不会猜测填入；存在失败题目时只尝试暂存，不自动提交。所用 API/模型需支持 JSON Object 模式。
  - 智慧树作业/考试保留原有逐题纯文本协议。
- **自动 DOM 填入**：
  - 适配超星学习通 **章节测验**（嵌套 iframe 内部题目自动提取、答案匹配点击、自动暂存）。
  - 适配超星学习通 **独立作业/考试页**（`.questionLi` 结构高精度匹配与填入）。
  - 超星选择题按选项顺序匹配，支持无可见字母的选项与 `√/×` 判断题；多选会取消多余勾选，并在点击后核验选中状态。
  - 适配智慧树 **在线测试/作业**。
- **超星字体混淆处理（可切换）**：
  - **查现有指纹表（默认）**：本地解析字体并匹配内置字形表，无需识图请求；未命中不会自动切换策略。
  - **图片视觉识别**：将实际用到的混淆汉字渲染成编号图片，每批最多 40 字，识别为正常文字后继续原有解题流程。
  - 视觉 API 可选择**复用主解题模型**或**独立 Base URL / API Key / Model**；两套参数不混用、不自动回退。
  - 覆盖超星章节测验、独立作业/考试和视频弹题；不改写宿主页面文字、字体或事件绑定。
- **安全保障**：
  - 默认开启“自动提交”，可在控制面板关闭；建议在 AI 答题完成后人工核对答案。
  - 字体解析失败、字形表未命中、识图 JSON 缺字/无效时不继续解题或自动提交；视觉模型仍可能把一个字识别成另一个合法汉字，建议关闭自动提交后核对。

### 3. 现代化悬浮控制面板
- **不污染宿主样式**：纯原生隔离样式渲染，避免与目标网页 CSS 冲突。
- **可平滑拖拽**：右上角胶囊浮球，支持随意拖拽到屏幕任意位置，坐标自动持久化保存。
- **功能分栏**：
  - 📊 **控制仪表盘**：当前运行状态实时显示、一键手动答题、强制下一节、实时日志窗口。
  - 🎬 **视频设置**：连播开关、倍速选择（1.0x ~ 2.5x）、静音开关、弹题处理开关。
  - 🧠 **AI 接口配置**：Base URL、API Key（支持明文隐藏切换）、Model、自动提交开关、**⚡ 一键测试 API 连接** 按钮。

### 配置 OpenAI API（初次使用）
1. 打开任意超星/学习通或智慧树课程页面，页面右上角会出现 `[🤖 刷课酱]` 悬浮按钮。
2. 点击按钮右侧的 `⚙️` 图标打开控制台。
3. 切换到 **【🧠 AI 接口配置】** 标签页：
   - **API 接口地址**：填写您的 API 服务地址（例如 `https://api.deepseek.com/v1` 或 `https://api.openai.com/v1`）。
   - **API Key**：填写您的密钥（例如 `sk-...`）。
   - **模型名称**：填写对应的模型 ID（例如 `deepseek-chat` 或 `gpt-4o-mini`）。
4. 点击 **【⚡ 测试 API 连接】**，确认弹出连接成功的提示。
5. 点击 **【💾 保存 API 配置】**；其它开关和倍速设置会自动保存。

### 配置超星字体混淆策略

进入控制台 **【🧠 AI 接口配置】→【超星字体混淆处理策略】**：

1. 默认选择 **查现有指纹表**。若字形不在表中，日志会提示失败；需手动改用视觉策略或人工处理。
2. 选择 **图片视觉识别** 后，再选择视觉 API 来源：
   - **复用主解题模型**：使用已保存的主 API 地址、密钥、模型；该模型必须支持图片输入和 JSON Object 输出。
   - **独立视觉 API**：填写三个独立参数并点击 **保存 API 配置**。视觉模型只识字，正常文字仍交给主模型解题。
3. 策略和来源选择自动保存；API 参数手动保存。切换到查表或复用模式不会清空已保存的独立参数。

仅视觉策略会把**编号汉字图片**发往所选 API，不上传整页截图；识别后的题目文本仍按原有流程发给主解题 API。现有“测试 API 连接”只测试主模型文本响应，不代表它支持图片。切换策略/相关 API 设置会取消正在识别或答题的旧任务，需重新触发作答。

详细限制、数据流和测试说明见 [字体混淆处理说明](docs/font-handling.md)。

## CI / CD 自动发版

- **普通 push 到 `main` / 面向 `main` 的 PR**：只运行 CI（版本一致性、构建、产物同步及全部测试），不创建 Release。
- **push 新的 `vX.Y.Z` 标签**：运行 CD，复用 CI 验证标签提交；全部通过后自动创建 GitHub Release 并上传已验证的 `shuakejiang.user.js`。
- 标签版本必须与 `package.json`、`src/header.js`、生成脚本一致；失败不发布，不覆盖已有 Release。

发版时不再需要手动执行 `gh release create`。具体步骤和更新渠道区别见 [CI / CD 与发版流程](docs/releasing.md)。

## 📌 处理逻辑说明

超星学习页采用「顶层框架统一编排 + 同源 iframe 递归访问」的模型（与参考扩展一致）：

1. **路由指纹**：`顶层地址 + #iframe.src + #iframe 文档地址` 变化即视为切章，重新扫描任务点。
2. **任务点扫描**：读取 `#iframe` 文档内所有 `/ananas/modules/<type>`（含 `/ananas/dialog/ballchart`）与批注任务点；无任务点时按“图文任务点”处理。
3. **顺序执行**：按顺序跳过已完成任务点（`ans-job-finished` / 测验状态 / 播放至末尾），执行视频/音频、文档翻阅、章节测验、图文。
4. **队列排空**：只点击当前页面的 `#prevNextFocusNext`、备用【下一节】入口或当前章节任务点标签卡；不会读取 `#coursetree` 回跳已离开的章节。
5. **安全兜底**：没有可跳转入口时二次确认并停止。

### 已知限制
- 超星字体处理目前支持 `.font-cxsecret` 标记、题目所属文档的**内联 Base64 字体**；外链字体、同名字体存在多份不同数据等不明确情况会失败并阻止自动提交。旧字形表并不保证覆盖当前所有字体；视觉转写也可能误识别。此功能不提供通用图片题 OCR。
- 智能树视频弹题的自动作答需要在**页面上下文**注入桥接脚本，若脚本管理器/站点 CSP 阻止注入，则需手动完成弹题。
