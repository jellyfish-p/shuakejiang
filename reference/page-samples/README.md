# 本地页面样本

本目录收纳用于 DOM 对照的真实网页快照，与原插件解包资料分开。样本子目录由 Git 忽略，不参与构建，也不是自动化测试默认加载的 fixture。

## 现有样本

| 路径 | 归档前位置 | 说明 |
| --- | --- | --- |
| `chaoxing/question.html` | `patched/question.html` | 现有超星页面 HTML，保留原内容 |
| `chaoxing/icomoon.ttf` | `patched/icomoon.ttf` | 同目录原有字体资源，保留原文件名 |

这两份文件只是整体搬移，没有清洗、修复引用或修改内容。原目录名 `patched/` 不表示它们是修补后的扩展，因此没有并入原插件版本目录。未补录无法核实的采集时间、账号或课程信息。

## 使用边界

- 优先静态阅读 HTML，核对真实元素、iframe、按钮和弹窗结构；不要默认运行其中的脚本或加载远程资源。
- 页面可能含用户、课程、题目或带参数的链接，公开前需要脱敏；保持忽略，不直接提交原始快照。
- 单凭 `.ttf` 扩展名不能认定 `icomoon.ttf` 就是 `font-cxsecret` 混淆字体，应以页面实际 `@font-face` 和字体使用关系为准。
- 如需回归测试，应另行制作最小、脱敏、可重现的 fixture，不让测试依赖本地私有快照。
